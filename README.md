# Graduation Project - مشروع التخرج

تطبيق ومشرع التخرج التفاعلي.

## نظام المشاركة المشترك (كود + دردشات)
- **الكود والملفات:** موجودة في الجذر والمجلدات المخصصة.
- **قواعد الذكاء الاصطناعي:** موجودة في `.agents/AGENTS.md`.
- **سجلات المحادثات والخطط:** موجودة في مجلد `chats/`.

## المزامنة بين الفريق
لرفع الكود والدردشات معاً:
```bash
git add .
git commit -m "Update project code and chat logs"
git push origin main
```
