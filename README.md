# Html Course with Antigravity

مشروع دورة HTML/CSS التفاعلية ومشاركتها باستخدام Antigravity و Git.

## محتويات المشروع
- دروس وتمارين HTML & CSS
- نماذج الجداول، الشبكات (CSS Grids)، الصور والشيكولات المختلفة
- إعدادات وقواعد Antigravity المخصصة للذكاء الاصطناعي في مجلد `.agents`

## كيفية التعاون في المشروع
1. عند إجراء أي تعديل، قم بعمل `git add` و `git commit` ثم `git push`.
2. يستقبل زميلك التعديلات بعمـل `git pull`.
