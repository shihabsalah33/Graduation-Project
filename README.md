# Graduation Project - مشروع التخرج 🚀

المشروع التفاعلي وتطبيق مشروع التخرج المزامن للفريق.

## 🌟 الميزات والمكونات المحدثة:
- **المزامنة التلقائية الصامتة:** خدمة خلفية خفية (`auto_sync_service.py`) تعمل في خلفية الويندوز.
- **منصة الشات وتاريخ الكود:** تتوفر منصة تفاعلية أنيقة بتبويبات منسقة في [`chats/chat_history.html`](file:///c:/Users/shiha/Desktop/%D9%85%D8%B4%D8%B1%D9%88%D8%B9%20%D8%A7%D9%84%D8%AA%D8%AE%D8%B1%D8%AC/chats/chat_history.html).
- **الرجوع والتنقل الزمني المؤكد:** إمكانية معايرة وتأكيد الرجوع لأي نقطة زمانية سابقة بأمان.

## 🛠️ تثبيت الخدمة لأعضاء الفريق:
يكفي فتح مجلد المشروع والضغط مرتين على:
