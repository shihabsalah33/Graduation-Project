# Antigravity Shared Collaboration & Security Rules

## 1. التزامن التلقائي الصامت وفي الخلفية (Silent Auto-Sync Background Execution)
- 🔄 **اكتشاف وجلب التحديثات تلقائياً (Auto Fetch & Pull):**
  - عند استلام أي رسالة من Shihab أو من زميله، ينفذ الذكاء الاصطناعي أوتوماتيكياً وفي الخلفية وبدون طلب أي موافقات يدوية أمر: `git fetch origin main` و `git pull origin main` للتحقق فوراً واكتشاف وجود أي رسائل أو كود جديد مرفوع من الطرف الآخر.

- 📤 **حفظ ورفع الهيستوري صامتاً في الخلفية (Silent Auto-Push):**
  - بمجرد الرد على أية رسالة، يكتب الذكاء الاصطناعي الرسالة فوراً في `chats/chat_history.md` باسم كاتبها (Shihab أو اسم الزميل)، وينفذ تلقائياً في الخلفية وبدون طلب موافقات:
    `git add chats/chat_history.md`
    `git commit -m "Auto-update chat log"`
    `git push origin main`

## 2. معاملة الزميل كمراسل مستقل (Independent Colleague Identity)
- 👤 **تحديد هوية الراسل:**
  - يتم التعامل مع الزميل كمراسل مستقل ومشارك في المشروع بحسابه الخاص.
  - يتم توثيق أسئلته وإجاباته في الهيستوري تحت اسمه الصريح (مثلاً: `👤 العضو: Mohammed` أو `👤 العضو: Mostafa`).

## 3. طباعة سجل المراسلات الكامل (Full History Transcript)
- 📜 **السجل التراكمي الكامل:**
  - ملف `chats/chat_history.md` يُعتبر هو مرجع المحادثة الموحد والمستمر للمشروع، ويحتوي على النص الكامل لكافة الرسائل والردود بين جميع الأطراف والذكاء الاصطناعي.

## 4. صلاحيات التعديل وإنشاء الملفات (Collaborator Permissions)
- 🚫 **منع إنشاء ملفات جديدة للزميل:** يُمنع حظرًا تامًا إنشاء أي ملفات كود/مشروع جديدة لزميل العمل دون موافقة صريحة من مالك المشروع (Shihab).
- 📝 **التعديل على الملفات النصية الحالية فقط:** يُسمح فقط بالتعديل على ملفات الكود والملفات النصية الموجودة حالياً داخل المشروع.
- 🛑 **طلب الموافقة والمراجعة (Approval Required):** أي تغيير هيكلي يجب تقديمه عبر **Pull Request** لمراجعته واعتماده من المالك قبل التطبيق.
