# Antigravity Shared Collaboration & Security Rules

## 1. التزامن التلقائي الصامت وفي الخلفية (Silent Auto-Sync Background Execution)
- 🔄 **اكتشاف وجلب التحديثات تلقائياً (Auto Fetch & Pull):**
  - عند استلام أي رسالة من Shihab أو من زميله، ينفذ الذكاء الاصطناعي أوتوماتيكياً وفي الخلفية وبدون أي موافقات يدوية: `git fetch origin main` و `git pull origin main` للتحقق فوراً واكتشاف أي رسائل جديدة.

- 📤 **حفظ ورفع الهيستوري صامتاً في الخلفية (Silent Auto-Push):**
  - عند الرد، يكتب الذكاء الاصطناعي الرسالة فوراً في `chats/chat_history.html` و `chats/chat_history.md` بالتنسيق البصري المطلوب، وينفذ تلقائياً في الخلفية:
    `git add chats/`
    `git commit -m "Auto-update formatted chat history"`
    `git push origin main`

## 2. تحديد هوية المستخدم وتنسيق الرسائل (User Detection & Chat UI Styling)
- 👤 **تحديد هوية الكاتب:**
  - التعرف التلقائي والمستقل على صاحب الرسالة (Shihab أو اسم الزميل مثل Mostafa).

- 🎨 **تنسيق البابل والتصميم (مطابق للصورة تماماً):**
  - **بدون تواريخ أو أوقات.**
  - فوق كل رسالة يظهر اسم صاحبها صراحة (`👤 Shihab` أو `👤 Mostafa` أو `🤖 Antigravity`).
  - رسالة المستخدم تظهر داخل فقاعة رمادية داكنة أنيقة بحواف منحنية (Dark rounded bubble) تحتوي النص الكامل للرسالة.
  - إجابة Antigravity تظهر أسفلها مباشرة بالنص التفصيلي الأنيق.
  - يتم التخزين داخل ملف `chats/chat_history.html` منسق وجاهز للعرض المباشر والمريح عند الفتح في المتصفح، بجانب `chats/chat_history.md`.

## 3. عدم سرد "آخر رسالة" عند الاستئناف (No Auto-Recap on Resume)
- 🔇 **الرد المباشر بدون مقدمات:**
  - عند فتح دردشة جديدة أو طلب الاستئناف، يتم المزامنة صامتاً، والإجابة على طلب المستخدم مباشرة دون كتابة جمل مثل "آخر رسالة في الهيستوري كانت كذا...".

## 4. صلاحيات التعديل للمشروع (Collaborator Permissions)
- 🚫 **منع إنشاء ملفات جديدة للزميل:** يُمنع حظرًا تامًا إنشاء أي ملفات كود/مشروع جديدة لزميل العمل دون موافقة صريحة من مالك المشروع (Shihab).
- 📝 **التعديل على الملفات الحالية فقط:** يُسمح فقط بالتعديل على الملفات الموجودة حالياً داخل المشروع بعد مراجعتها.
