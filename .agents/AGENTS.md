# Antigravity Shared Collaboration & Security Rules

## 1. لغة التواصل وتوثيق الدردشات المشتركة
- **لغة التواصل:** العربية والإنجليزية.
- **حفظ الدردشات والرسائل تلقائياً إلى GitHub:** 
  - يُلزم الذكاء الاصطناعي على جهاز أي زميل/مشارك بتوثيق وحفظ جميع الرسائل والقرارات والتعديلات داخل ملف جديد بنمط `chats/session_colleague_<date>.md`.
  - يتم التوجيه لعمل `git add chats/` و `git commit` لرفع رسائل ومحادثات الجلسة إلى GitHub تلقائياً حتى يراها مالك المشروع (Shihab).

## 2. صلاحيات التعديل وإنشاء الملفات (Collaborator Permissions)
- 🚫 **منع إنشاء ملفات جديدة للمشروع:** يُمنع حظرًا تامًا إنشاء أي ملفات كود/مشروع جديدة دون إذن صريح وموافقة مسبقة من مالك المشروع (Shihab).
- 📝 **التعديل على الملفات النصية الحالية فقط:** يُسمح فقط بالتعديل على ملفات الكود والملفات النصية الموجودة حالياً داخل المشروع.
- 🛑 **طلب الموافقة والمراجعة (Approval & Review Required):** أي تغيير هيكلي يجب تقديمه عبر **Pull Request** لمراجعته واعتماده من المالك قبل التطبيق.
