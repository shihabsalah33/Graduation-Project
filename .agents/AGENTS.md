# Antigravity Shared Collaboration & Security Rules

## 1. التحديث والتزامن التلقائي (Automatic Git Sync)
- **سحب التحديثات تلقائياً (Auto Pull):** 
  - عند فتح أي جلسة دردشة جديدة أو إرسال أي سؤال/طلب من المستخدم أو الزميل، يلتزم الذكاء الاصطناعي بتشغيل أمر `git pull origin main` تلقائياً أولاً لجلب أحدث التعديلات والرسائل المرفوعة من بقية الأعضاء.
- **رفع التحديثات والدردشات تلقائياً (Auto Push):**
  - عند الانتهاء من أي تعديل أو حفظ ملخص محادثة جديدة في مجلد `chats/`، يلتزم الذكاء الاصطناعي بتنفيذ `git add .` ثم `git commit` ثم `git push origin main` تلقائياً لتصل التعديلات والدردشات فوراً لجميع المشاركين.

## 2. لغة التواصل وتوثيق الدردشات
- **لغة التواصل:** العربية والإنجليزية.
- **حفظ الدردشات:** يتم قراءة وتحديث سياق المحادثات من مجلد `chats/` باستمرار.

## 3. صلاحيات التعديل وإنشاء الملفات (Collaborator Permissions)
- 🚫 **منع إنشاء ملفات جديدة:** يُمنع حظرًا تامًا إنشاء أي ملفات كود/مشروع جديدة لزميل العمل دون موافقة صريحة من مالك المشروع (Shihab).
- 📝 **التعديل على الملفات النصية الحالية فقط:** يُسمح فقط بالتعديل على ملفات الكود والملفات النصية الموجودة حالياً داخل المشروع.
- 🛑 **طلب الموافقة والمراجعة (Approval Required):** أي تغيير هيكلي يجب تقديمه عبر **Pull Request** لمراجعته واعتماده من المالك قبل التطبيق.
