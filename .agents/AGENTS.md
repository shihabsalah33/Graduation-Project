# Antigravity Shared Collaboration Rules

1. **لغة التواصل:** العربية والإنجليزية.
2. **مشاركة الدردشات والخطط:** 
   - يتم توثيق وحفظ جميع المحادثات والخطط القرارية الهامة داخل مجلد `chats/` في المشروع بانتظام.
   - عند بدء أي جلسة جديدة أو استلام تحديثات من الفريق، يقرأ Antigravity ملفات مجلد `chats/` لاستكمال العمل بفهم كامل لسياق الدردشات السابقة.
3. **تزامن التغييرات:** يتم رفع الكود وملفات الدردشة معاً في كل `git push` ليكون الفريق وجميع جلسات الذكاء الاصطناعي على نفس مستوى التحديث.
