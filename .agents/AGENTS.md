# Antigravity Shared Collaboration & Security Rules

## 1. استئناف المحادثة والتحديث التلقائي (Auto Resume & Git Pull Trigger)
- **أمر استئناف الجلسة وقراءة السجل:**
  - عند كتابة أي كلمة أو طلب مثل: `اقرأ سجل المحادثة` أو `استأنف الجلسة من chat_history.md` أو فتح الشات:
    1. ينفذ الذكاء الاصطناعي **`git pull origin main` تلقائياً فوراً** لسحب أحدث الرسائل والكود المرفوع من جميع الأعضاء.
    2. يقرأ محتوى `chats/chat_history.md` ويكتب إشعاراً بعرض السجل وتأكيد استئناف المحادثة من نفس النقطة.

- **🚀 الرفع التلقائي (Auto Push):**
  - عند كتابة أي سؤال أو إجابة، يتم تسجيلها في `chats/chat_history.md` ثم تشغيل `git add .` وتحديد الرسالة باسم الكاتب، ورفعهما فوراً بـ `git push origin main`.

## 2. تنسيق تسجيل الرسائل والأسئلة باسم الكاتب (Chat Format with Names)
يتم تسجيل كل سؤال وجواب داخل `chats/chat_history.md` بالطريقة التالية:
```markdown
---
### 👤 العضو: [اسم العضو - مثلاً Shihab أو اسم الزميل]
🗓️ **التاريخ والوقت:** [التاريخ والوقت الحقيقي]
❓ **السؤال/الطلب:** [نص سؤال العضو]
🤖 **رد Antigravity:** [نص الإجابة والتعديلات]
```

## 3. صلاحيات التعديل وإنشاء الملفات (Collaborator Permissions)
- 🚫 **منع إنشاء ملفات جديدة للزميل:** يُمنع حظرًا تامًا إنشاء أي ملفات كود/مشروع جديدة لزميل العمل دون موافقة صريحة من مالك المشروع (Shihab).
- 📝 **التعديل على الملفات النصية الحالية فقط:** يُسمح فقط بالتعديل على ملفات الكود والملفات النصية الموجودة حالياً داخل المشروع.
- 🛑 **طلب الموافقة والمراجعة (Approval Required):** أي تغيير هيكلي يجب تقديمه عبر **Pull Request** لمراجعته واعتماده من المالك قبل التطبيق.
