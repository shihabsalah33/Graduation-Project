# Antigravity Shared Collaboration & Security Rules

## 1. التزامن الصامت الخفي 100% (Silent Invisible Auto-Sync & Zero Output Noise)
- 🔄 **جلب التحديثات (Fetch & Pull):**
  - **يُمنع تنفيذ `git pull` أو `git fetch` مع كل رسالة فردية.**
  - يتم التزامن والجلب فقط عند أول دخول/جلسة جديدة أو بناءً على طلب صريح، لعدم إظهار أوامر تشغيل ملغاة في الواجهة.

- 📤 **حفظ ورفع الهيستوري صامتاً وبدون إعلان (Invisible Auto-Push):**
  - يكتب الذكاء الاصطناعي الرسالة فوراً في `chats/chat_history.html` و `chats/chat_history.json` و `chats/chat_history.md` بالتنسيق المطلوب.

- 🔇 **منع طباعة أي تفاصيل فنية عن التزامن (Zero Technical Noise):**
  - **يُحظر حظراً تاماً** ذكر أو كتابة أي شرح عن خطوات Git (مثل: `git pull`, `git push`, `تم رفع السجل`, `تم التحديث في الخلفية`, إلخ) في الرد المرسل للمستخدم. يتم الإجابة على طلب المستخدم مباشرة فقط وبشكل طبيعي.

## 2. تحديد هوية المستخدم وتنسيق الرسائل (User Detection & Chat UI Styling)
- 👤 **تحديد هوية الكاتب:**
  - التعرف التلقائي والمستقل على صاحب الرسالة (Shihab أو اسم الزميل مثل Mostafa).

- 📷 **التعرف على الصور والرسائل بدون نص (Image & Attachment Detection):**
  - عند إرسال صورة فقط (أو صورة مرفقة)، يتم اكتشاف محتواها الدقيق وتدوين ملاحظة توضيحية داخل الفقاعة باسم المستخدم، مثل: `📷 [صورة مرفقة: خيارات القائمة Context Menu]`.

- 🤖 **التسجيل الحرفي والدقيق لإجابة الذكاء الاصطناعي (Verbatim Exact AI Response):**
  - تدوين وحفظ الرد الكامل والحرفي كما صُدر من Antigravity دون أي اختصار أو تبسيط في السجل التاريخي.

- 🎨 **تنسيق البابل والتصميم (مطابق للصورة تماماً):**
  - **بدون تواريخ أو أوقات.**
  - فوق كل رسالة يظهر اسم صاحبها صراحة (`👤 Shihab` أو `👤 Mostafa` أو `🤖 Antigravity`).
  - رسالة المستخدم تظهر داخل فقاعة رمادية داكنة أنيقة بحواف منحنية (Dark rounded bubble) تحتوي النص الكامل أو وصف الصورة.
  - إجابة Antigravity تظهر أسفلها مباشرة بالنص التفصيلي الحرفي الكامل.

## 3. عدم سرد "آخر رسالة" أو ملخصات عند الاستئناف (No Auto-Recap)
- 🔇 **الرد المباشر بدون مقدمات:**
  - عند فتح دردشة جديدة أو طلب الاستئناف، يتم المزامنة صامتاً، والإجابة على طلب المستخدم مباشرة دون أي مقدمات أو ملخصات.

## 4. صلاحيات التعديل للمشروع (Collaborator Permissions)
- 🚫 **منع إنشاء ملفات جديدة للزميل:** يُمنع حظرًا تامًا إنشاء أي ملفات كود/مشروع جديدة لزميل العمل دون موافقة صريحة من مالك المشروع (Shihab).
- 📝 **التعديل على الملفات الحالية فقط:** يُسمح فقط بالتعديل على الملفات الموجودة حالياً داخل المشروع بعد مراجعتها.
