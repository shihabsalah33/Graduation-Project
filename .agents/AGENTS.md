# Antigravity Collaboration Rules

1. **لغة التواصل:** العربية والإنجليزية.
2. **معايير الكود:** كتابة كود HTML5 نظيف ومنسق مع استخدام تعليقات واضحة لدروس CSS والـ Layout.
3. **مشاركة التغييرات:** توثيق الأفكار وتعديلات الذكاء الاصطناعي في الملفات المخصصة حتى تكون متزامنة بين جميع المشاركين في المشروع.
