# Antigravity Shared Collaboration & Security Rules

## 1. التحديث وسحب التعديلات من GitHub (Mandatory Auto Pull)
- ⚡ **سحب التحديثات فورياً عند كل رسالة:**
  - عند استلام أي رسالة أو طلب في الشات، **أول خطوة ينفذها الذكاء الاصطناعي إجبارياً قبل الإجابة** هي تشغيل أمر `git pull origin main` لجلب جميع المراسلات والتعديلات المرفوعة على GitHub.

## 2. طباعة واستئناف سجل المراسلات الكامل (Full History Transcript)
- 📜 **عرض السجل الكامل حرفياً بدون اختصار:**
  - عند طلب استئناف الجلسة أو قراءة `chat_history.md`، يلتزم الذكاء الاصطناعي بطباعة **نص جميع المراسلات والأسئلة والأجوبة السابقة بالكامل حرفياً** (أسئلة Shihab وإجاباتها، وأسئلة الزميل وإجاباتها) من البداية للنهاية، وعدم الاكتفاء بنقاط ملخصة.

## 3. التوثيق والرفع التلقائي (Auto Push)
- 📤 **حفظ ورفع كل رسالة:**
  - يتم إضافة السؤال والجواب الجديدين إلى `chats/chat_history.md` بالاسم الصريح، ثم تنفيذ `git add .` و `git commit` و `git push origin main` تلقائياً فوراً لتصل التعديل للطرف الآخر.

## 4. تنسيق سجل المراسلات (Chat Format with Names)
```markdown
---
### 👤 العضو: [اسم العضو - Shihab أو اسم الزميل]
🗓️ **التاريخ والوقت:** [التاريخ والوقت الحقيقي]
❓ **السؤال/الطلب:** [نص سؤال العضو بالكامل]
🤖 **رد Antigravity:** [نص الإجابة والتعديلات بالكامل]
```

## 5. صلاحيات التعديل وإنشاء الملفات (Collaborator Permissions)
- 🚫 **منع إنشاء ملفات جديدة للزميل:** يُمنع حظرًا تامًا إنشاء أي ملفات كود/مشروع جديدة لزميل العمل دون موافقة صريحة من مالك المشروع (Shihab).
- 📝 **التعديل على الملفات النصية الحالية فقط:** يُسمح فقط بالتعديل على ملفات الكود والملفات النصية الموجودة حالياً داخل المشروع.
- 🛑 **طلب الموافقة والمراجعة (Approval Required):** أي تغيير هيكلي يجب تقديمه عبر **Pull Request** لمراجعته واعتماده من المالك قبل التطبيق.
